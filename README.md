# The Spirit Animal Podcast

[Open the public site](https://auraofintelligence.github.io/spirit-animal-podcast/)

A bold, joyful public home and production workbench for The Spirit Animal Podcast.

Guests choose their own animal. The animal brings a set of values into the room. The conversation follows those values past the usual human story and towards something honest, funny, useful or beautifully strange.

## Inside

- the original podcast premise and episode rhythm
- a browser-local Animal Compass
- episode sparks and recurring show bits
- Markdown builders for guest notes, episode maps, run sheets, segments and source trails
- a touch-friendly recording cockpit with timers, markers, notes and export
- public links to the wider Minjerribah media and project network

Drafts in the interactive tools stay in the browser until copied, downloaded or cleared.
